# Autonomy, production, and controller safety

standard remains default; background_exterior is explicit opt-in; AQ is an opt-in standard overlay. Existing policies and historical evidence are never converted in place.

The authorized host/controller promotion service is the only canonical writer. Subagents and external controllers are advisers or isolated candidate producers. Assignments bind immutable inputs, exact allowed outputs, phase tool-profile hash, timeout, action budget, and prohibited capabilities. Reject extra files, stale hashes, partial output, links, path escape, duplicate actions, unbounded loops, and unattested client enforcement.

Server MCP registration, project-enabled MCP tools, and phase/controller profiles are distinct sets. Project enablement does not grant a phase authority. A phase profile may only narrow access and every intentional exclusion carries a reason. desktop_in_session provides workflow-contract enforcement only and is not an attested sandbox.

Quality pass, review-required, package, and handoff terminals remain distinct. Missing evidence is unscorable, never an invented pass. Preserve best-known evidence on budget, plateau, cycle, rollback, or bounded failure.

New AQ v2 material attempts collect one deterministic dependency closure, perform
host-owned provenance rebinding, and pass an isolated Blender shadow preflight plus neutral
preview before a material controller request can exist. Framework preflight failure creates
no user approval, controller invocation, promotion intent, or canonical write. Historical
terminal sessions are never resumed through technical retry evidence; a new repair session
must bind the exact old terminal, current geometry, scope, rollback baseline, and source
bytes without synthesizing authority.
