# Approvals and authorization

Every authority is exact-purpose, exact-hash, bounded, single-use, and fail-closed. A generic request or completion marker cannot replace InteriorScope, interior-camera, V0.6 revision/candidate promotion, bounded convergence, external intake, V0.7 optimization, migration plan/apply, Destination Handoff, failed-step retry, or controller-binding authority.

Before a side effect, acquire the relevant lock and re-read the exact plan, source map, approval/authorization file, predecessor chain, budget, and single-use state. Archive the baseline before canonical replacement. Promotion uses strict candidate validation and compare-and-swap; failure restores only an exact archive and records immutable failure/rollback evidence.

PolicyAuthorization records bounded policy-engine authority and is never approved_by=user. Controller/task completion never synthesizes approval. Changing a source, plan, profile, scope, target, operation, path family, delta, budget, output format, or destination requires a new plan and authorization.
