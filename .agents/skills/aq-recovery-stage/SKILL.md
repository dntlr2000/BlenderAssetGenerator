# AQ recovery stage

1. Distinguish dependency, path/hash, manifest, schema/projection, controller, rollback, budget, and genuine scope failures.
2. Preserve all failed attempts, best-known candidates, policy decisions, and terminal evidence.
3. Revalidate exact retry or rollback eligibility and consume only the existing single-use host authority.
4. Never ask the user to approve a purely technical repair.
5. Stop at safe review, consolidated genuine escalation, blocked, failed, or cancelled terminal when bounded recovery cannot proceed.
