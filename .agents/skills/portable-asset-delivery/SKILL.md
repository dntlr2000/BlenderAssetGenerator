# Portable asset delivery

1. Start from current canonical geometry, material, build, and QA evidence.
2. Generate exact preflight, review plan, and optimization review before requesting authorization.
3. Stop for the specialized V0.7 optimization-plan SHA-256 approval; the entry-skill invocation does not provide it.
4. Operate only in run-owned derived directories and preserve canonical authoring inputs.
5. Require an immutable package manifest and fresh clean-import round trip for every accepted format.
6. Never claim destination runtime parity or write a destination project.
