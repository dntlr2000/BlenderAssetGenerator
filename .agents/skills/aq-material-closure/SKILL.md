# AQ material closure

1. Start only from exact current material candidate, request, assignment, completion, graph, UV, and canonical-snapshot evidence.
2. Validate dependency closure, material identity, UV fingerprint, surface-detail ownership, budget, and state consistency.
3. Perform host-only graph rebinding and isolated Blender shadow compilation without changing canonical asset evidence.
4. Publish a neutral preview before any appearance decision required by the existing contract.
5. Consume only the exact user appearance approval or non-user policy authorization type accepted by the existing host boundary.
6. Route technical failure to AQ recovery and never transform it into a user approval request.
