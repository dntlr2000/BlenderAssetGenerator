# AQ delivery stage

1. Require an accepted IQ source freeze before production delivery planning.
2. Preserve exact V0.7 optimization-plan authorization, immutable package manifest, and format-specific clean-import evidence.
3. Keep review-only bundles distinct from production packages and destination handoff sources.
4. Never write Unity, Unreal, or another destination project or claim runtime parity.
5. Publish only the terminal type supported by rehashed package/roundtrip or review evidence.
